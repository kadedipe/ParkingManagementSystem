# ============================================================================
# SEO Best Practices
# ============================================================================

# 1. Allow access to content that should be indexed
# 2. Block access to admin, private, and API endpoints
# 3. Use sitemap to guide crawlers to important pages
# 4. Use crawl-delay to be respectful to servers
# 5. Monitor crawler activity in server logs

# ============================================================================
# Common Mistakes to Avoid
# ============================================================================

# ❌ Don't block CSS/JS files - this can harm SEO
# ❌ Don't use the same robots.txt for all environments
# ❌ Don't forget to update sitemap URL
# ❌ Don't block crawlers from all content accidentally

# ✅ Do test robots.txt in Google Search Console
# ✅ Do use environment-specific robots.txt
# ✅ Do keep your sitemap updated
# ✅ Do monitor crawler errors

# ============================================================================
# Testing Your Robots.txt
# ============================================================================

# Use Google Search Console to test your robots.txt:
# 1. Go to Google Search Console
# 2. Navigate to "robots.txt Tester"
# 3. Enter your robots.txt content
# 4. Test different URLs to see if they're allowed
